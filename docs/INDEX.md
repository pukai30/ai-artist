## 🎯 Quick Commands

### Essential Commands
```bash
# Start the Streamlit app
streamlit run streamlit_app.py

# Run tests
python test_streamlit_integration.py

# View demo prompts
python demo_prompts.py

# View all templates
python prompt_temp.py
```

### Windows Shortcuts
```bash
# Double-click in Explorer
run_streamlit.bat

# Or in PowerShell
.\run_streamlit.bat
```

### Mac/Linux Shortcuts
```bash
# Make executable (first time only)
chmod +x run_streamlit.sh

# Run
./run_streamlit.sh
```
